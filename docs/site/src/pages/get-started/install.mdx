# Install

macOS, Linux, and Windows.

::::code-group

```sh [Homebrew (macOS / Linux)]
brew install tenequm/tap/pond
```

```sh [Nix]
nix profile add github:tenequm/pond#pond
```

```sh [Cargo]
# Requires protoc on PATH: winget install Google.Protobuf (Windows) or system package manager.
cargo install pond-db   # installs the `pond` binary
```
