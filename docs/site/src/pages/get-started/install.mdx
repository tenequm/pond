# Install

macOS, Linux, and Windows.

::::code-group

```sh [Homebrew (macOS / Linux)]
brew install tenequm/tap/pond
```

```sh [Nix]
nix profile add github:tenequm/pond#pond
```

```sh [cargo-binstall (prebuilt, Windows-friendly)]
# Downloads the prebuilt binary (no protoc required).
cargo binstall pond-db
```

```sh [Cargo (build from source)]
# Requires protoc on PATH on Windows (winget install Google.Protobuf).
# macOS and Linux vendor protoc automatically.
cargo install pond-db
```
