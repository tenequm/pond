# Install

macOS and Linux. Windows is out of v1 scope.

```sh
brew install tenequm/tap/pond                  # Homebrew
nix profile add github:tenequm/pond#pond      # Nix
cargo install pond-db                           # crates.io (installs `pond`)
```

macOS selects the Metal backend automatically; elsewhere a CPU fallback runs.
