# Pond - project instructions

## Documentation

- **ASCII-only.** All Markdown and other documentation files in this repo must use ASCII characters only. No section signs, em/en dashes, smart quotes, infinity, micro, arrows, emoji, etc. Use plain replacements: `Section 5` instead of section-sign + 5, `inf` for infinity, `us` for microseconds, `->` for arrows, `-` for any dash variant. This applies to anything written into the repo, including `docs/references/**`.
